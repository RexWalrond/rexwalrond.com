# rexwalrond.com

Static personal site for Rex Walrond, served by GitHub Pages from `docs/`.

- Edit content in `build.py` and styles in `src/style.css`; photos live in `src/images/`.
- `python3 build.py` builds a preview (noindex). `python3 build.py --live` builds the production site (indexable, with CNAME).
